# Contribute / 贡献

For a correction, include the stable item ID, source post, and proposed change. For a new prompt, include its full text, model, original creator, source link, and redistribution permission where available.

纠错请提供案例 ID、原帖与修改内容。投稿请提供完整 Prompt、模型、原作者、来源链接及已有的再分发许可。

Generated JSON, README and browse pages are synchronized from MuseSignal. Contributions are reviewed and applied to the source dataset before the next export; manual edits to generated files may be replaced.

本库 JSON、README 与浏览页统一生成，贡献先审核并进入主数据，再同步到仓库。请使用 GitHub Issues，或联系 support@musesignal.com。
